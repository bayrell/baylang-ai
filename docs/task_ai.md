ТЗ по MCP в tech_spec_mcp_integration.md

Нужно доработать систему AI.

В core создать папку ai:
- messages, tools, mcp и т.п.

В базе данных будут таблицы:
- providers - хранить конфигурацмю провайдеров, например OpenRouter, OpenAI и т.п.
- models - конфигурация моделей. У каждого провайдера может быть свой список моделей.
- ai - конфигурация личностей ИИ
- ai_roles - конфигурация ролей ИИ. У одного ИИ может быть несколько ролей.

В python создать классы для провайдеров. У каждого свой класс. Учти что у разных провайдеров может быть разная конфигурация и опции. Например у openrouter можно отправлять дополнительные POST параметры, например список провайдеров, или динамический роутинг. Поэтому у каждого провайдера может быть своя реализация send. Все провайдера наследуются от базового класса. Также должен храниться список моделей провайдера.

Модели хранят конфигураций, название, температура и т.п.

AI хранит список моделей (может быть несколько, например для fallback). Системный промпт он же soul.

Пользователь с правами администратора может настраивать провайдеры, модели, AI.
