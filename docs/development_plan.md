## 🏗️ Фаза 1: Backend — Ядро системы
**Срок: 3–4 дня**

### 1.1 DI Container и конфигурация
- Улучшить `container.py` — добавить методы `reset()`, `has()`, `clear()`
- Добавить `Config` с `.env` загрузкой через `python-dotenv`
- Создать `CloudflareConfig` для серверless режима

### 1.2 API роуты
Создать следующие эндпоинты:

#### Авторизация (по ТЗ из `docs/auth.md`)
- `POST /api/auth/register` — регистрация пользователя
- `POST /api/auth/login` — вход в систему
- `POST /api/auth/logout` — выход
- `GET /api/auth/me` — текущий пользователь
- `POST /api/auth/refresh` — обновление токена

#### Профиль
- `GET /api/profile` — профиль пользователя
- `PUT /api/profile` — обновление профиля

#### Чат
- `POST /api/chat/message` — отправка сообщения ИИ
- `GET /api/chat/history` — история диалогов
- `DELETE /api/chat/history` — очистка истории
- `WebSocket /ws/chat` —实时 чат (для streaming ответов)

#### Системные
- `GET /api/health` — проверка здоровья сервера
- `GET /api/mcp/tools` — список доступных MCP инструментов

### 1.3 AI сервис
- Создать `ai_service.py` — обертку над OpenRouter API
- Добавить управление сессиями и контекстом
- Интегрировать MCP через `MCPManager` (по ТЗ из `docs/tech_spec_mcp_integration.md`)
- Добавить streaming ответов через SSE или WebSocket

### 1.4 База данных
- Создать схемы для пользователей, сессий, истории чата
- Добавить миграции (SQLite для dev, D1 для prod)
- Реализовать CRUD операции через репозитории

## 📝 Заметки и идеи

### Текущие проблемы
- Баг в `MCPClient.py`: переменная `method` вместо `method_name`
- `console.py` не интегрирован с MCP
- Нет README.md с инструкциями

### Архитектурные решения
- Использовать **JWT** для авторизации
- **SQLite** для локальной разработки, **D1** для продакшена
- **WebSocket** для实时 чата
- **MCP** для расширения возможностей ИИ

### Технологии
- Backend: FastAPI + Python 3
- Frontend: Vue 3 (Options API) + Rollup
- AI: OpenRouter API (GPT, Claude, Llama)
- БД: SQLite (dev) / D1 (prod)
- Деплой: Docker + Cloudflare Workers
